# Portafolio Digital - Teoría de la Programación

Repositorio listo para publicar en GitHub Pages.

## Contenido

- `index.html`: página principal.
- `assets/css/styles.css`: estilos.
- `assets/js/main.js`: menú responsive y galería.
- `assets/images/`: páginas del PDF exportadas como imágenes.
- `assets/original/PORTAFOLIO-DEFINITIVO.pdf`: PDF original.

## Cómo subirlo a GitHub

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos y carpetas de este proyecto.
3. Entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guarda y espera unos minutos.

La página quedará disponible en una URL similar a:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`
