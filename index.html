Algoritmo

Un algoritmo es un conjunto ordenado, finito y definido de instrucciones o reglas paso a paso que permiten solucionar un problema, realizar un cómputo o procesar datos. Funciona recibiendo datos de entrada, procesándolos mediante reglas lógicas y produciendo un resultado final.

El algoritmo calculodegalones convierte la producción diaria ingresada en litros a galones y calcula el monto total a cobrar según el precio por galón. Para ello, solicita litros y precio, convierte usando el factor 3.785 y multiplica los galones obtenidos por el precio ingresado.

Pseudocódigo

El pseudocódigo representa algoritmos usando lenguaje natural y estructuras similares al código, sin depender de reglas estrictas de sintaxis.

Algoritmo calculodegalones
  Definir litros, precioPorGalon Como Real
  Definir galones, totalACobrar Como Real

  Escribir "Ingrese la producción del día en litros"
  Leer litros
  Escribir "Ingrese el precio por galón"
  Leer precioPorGalon

  galones = litros / 3.785
  totalACobrar = galones * precioPorGalon

  Escribir "Equivalente en galones: ", galones
  Escribir "Total a cobrar: $", totalACobrar
FinAlgoritmo

Ejercicio con estructura secuencial en C

Problema: desarrollar un programa en lenguaje C que permita ingresar la base y la altura de un rectángulo, y calcule su área.

EntradaBase y altura
ProcesoÁrea = base × altura
SalidaÁrea del rectángulo
 
#include <stdio.h>

int main() {
  float base, altura, area;

  printf("Ingrese la base: ");
  scanf("%f", &base);

  printf("Ingrese la altura: ");
  scanf("%f", &altura);

  area = base * altura;
  printf("El área del rectángulo es: %.2f", area);

  return 0;
}

Ejercicio: control de ventas en una tienda

Se desea crear un programa que permita ingresar la cantidad de productos vendidos. Por cada producto se ingresa su precio. Si el precio es menor o igual a 0, el programa muestra un mensaje de error y vuelve a pedir el dato. Al final calcula el total, aplica 10% de descuento si supera los $100 y muestra el total final.

EntradaCantidad de productos vendidos y precio de cada producto.
ProcesoValidar cantidad, validar precios, acumular total, verificar descuento y calcular total final.
SalidaTotal de venta, descuento aplicado y total final a pagar.

Diagrama de flujo del ejercicio

Código en C

#include <stdio.h>

int main() {
  int cantidadProductos, i;
  float precio, total = 0;
  float descuento, totalFinal;

  do {
    printf("Ingrese la cantidad de productos vendidos: ");
    scanf("%d", &cantidadProductos);
    if (cantidadProductos <= 0) {
      printf("Ingrese una cantidad mayor que 0\n");
    }
  } while (cantidadProductos <= 0);

  for (i = 1; i <= cantidadProductos; i++) {
    do {
      printf("Ingrese el precio del producto #%d: ", i);
      scanf("%f", &precio);
      if (precio <= 0) {
        printf("Ingrese un precio válido\n");
      }
    } while (precio <= 0);
    total = total + precio;
  }

  if (total > 100) descuento = total * 0.10;
  else descuento = 0;

  totalFinal = total - descuento;
  printf("Total sin descuento: $%.2f\n", total);
  printf("Descuento aplicado: $%.2f\n", descuento);
  printf("Total a pagar: $%.2f\n", totalFinal);

  return 0;
}
